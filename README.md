# HCO BUG HUNTER

Advanced Web Security Assessment Tool for Termux/Linux.

**Code by Azhar - HCO**

## Features
- Authorization/scope confirmation
- DNS and TLS information
- HTTP response analysis
- Security-header checks
- Cookie security checks
- Same-scope URL discovery
- robots.txt / sitemap.xml checks
- Evidence-based findings
- Confidence levels
- Markdown and JSON reports
- Colorful Termux interface
- Local report storage

## Install

```bash
pkg update -y
pkg install python -y
git clone https://github.com/Hackerscolonyofficial/HCO-BUG-HUNTER.git
cd HCO-BUG-HUNTER
python hco_bug_hunter.py
```

## Important

This is an authorized-use assessment assistant. It does not guarantee that a
target is secure or insecure. Automated results must be manually reviewed
before being submitted as a security finding.

Only assess systems you own or have explicit written authorization to assess.
Respect program scope, rate limits and disclosure rules.

Do not use this project for unauthorized access, credential attacks, malware,
destructive exploitation, data theft, evasion, or disruption.
